## Default Permission

Nap's own pages may open the Nap browser, answer its sites' requests and show approvals.

#### This default permission set includes the following:

- `allow-open`
- `allow-close`
- `allow-respond`
- `allow-approve`
- `allow-registerListener`
- `allow-removeListener`
