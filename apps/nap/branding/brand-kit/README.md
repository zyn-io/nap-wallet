# Nap Wallet brand kit

Open `index.html` for the visual brand book. The complete written specification is in `BRAND-GUIDE.md`.

## Quick start

```html
<link rel="stylesheet" href="assets/brand-tokens.css">
<img src="assets/logo-horizontal.svg" alt="Nap Wallet">
```

Use `app-icon-light.svg` on light launch surfaces and `app-icon-dark.svg` on dark launch surfaces. The dark icon includes the required warm-ivory mole keyline.

## Source concept

This kit translates the approved mole-and-wallet direction into repeatable rules and SVG assets. The earlier raster concept sheets remain one directory above this kit for reference.
